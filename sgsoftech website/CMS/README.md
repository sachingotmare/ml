# SG Softech website

The site is served by the ASP.NET Core 8 application in `SGSoftech.Web.csproj`. The contact form posts to `/api/contact`, which sends an email to `sales@sgsoftech.in` through the configured SMTP account. The visitor's work email is set as the reply-to address; it is not used to impersonate the sender.

The IIS `web.config` registers `.webp` as `image/webp`, which is required for the solution photos to load on servers without a WebP MIME mapping.

For transferring the Release deployment ZIP to a Windows server, follow [IIS deployment instructions](IIS-DEPLOYMENT.md). Deploy the published application folder, not the source project or only `wwwroot`.

## Configure SMTP on IIS

1. Install the .NET 8 Hosting Bundle on the IIS server.
2. Publish this project and deploy the published output as an IIS application. Use an application pool configured for **No Managed Code**.
3. Configure these environment variables for the application on the server, keeping the SMTP password out of source control and deployment logs:
   - `Mail__Host`: SMTP server hostname
   - `Mail__Port`: SMTP port (typically `587`)
   - `Mail__Username`: SMTP account username
   - `Mail__Password`: SMTP password or provider-issued app password
   - `Mail__FromAddress`: verified sender mailbox on the SG Softech domain (defaults to `sales@sgsoftech.in`)
   - `Mail__EnableSsl`: `true`
4. Ensure the IIS server can make outbound TLS connections to the SMTP host and recycle the application pool after changing settings.

Until valid SMTP settings are available to the IIS application, the form returns an explicit service-unavailable message and does not report a false success.

## Website design and local preview

The homepage uses SG Softech's navy and magenta identity, industry-specific solution cards, an accessible industry filter, a requirements enquiry dialog, FAQs, and direct phone, email and WhatsApp links. All nine product pages use the same visual system. The supplied promotional images informed the product descriptions; existing local photographs provide industry context and do not represent client endorsements or photographs of the SG Softech team. The hero workflow is explicitly illustrative.

The installed UI/UX Pro Max and UI Styling guidance informed the responsive layout, focus states and reduced-motion behavior. The [21st.dev Features 8 reference](https://21st.dev/@meschacirung/components/features-8) informed the card-based visual direction. This is an original HTML/CSS implementation, not an imported React component; no 21st API key or new frontend framework is required.

Run locally:

```powershell
# Generated by GitHub Copilot - Oct-31-2026
dotnet run --project .\SGSoftech.Web.csproj --urls http://localhost:5188
```

Visit `http://localhost:5188`. The ASP.NET server is needed for `/api/contact`; opening the HTML file directly does not enable email delivery. Navigation, solution links and FAQs remain usable without JavaScript; filters and the enquiry dialog require it.

Static assets, scripts and fonts are served locally. Security headers restrict scripts and other resources to the site's origin, disable framing and deny unused device permissions. Configure HTTPS on IIS; HSTS is enabled outside Development. Do not add third-party scripts or resources without reviewing the content security policy.

The header and footer tagline is **Complete AI Software Solution**, with "AI" in the logo's sampled red (`#e1144f`). On phones, the homepage uses compact thumbnail-and-text solution rows, shorter imagery and tighter section spacing; all nine solution links and descriptions remain available. Product feature cards are also more compact without removing their descriptions.

The shared `wwwroot/js/page-motion.js` adds one-time fade-and-rise entrance animations to the homepage and product pages using IntersectionObserver and the browser's Web Animations API. It observes only until each element enters view, leaves content readable without JavaScript, skips keyboard-focused elements, and disables/cancels motion when reduced motion is requested. No animation library, continuous animation or scroll polling is needed.

## Reference-inspired visual refresh and backup

Before this refresh, the complete `CMS` folder was backed up to `../backups/CMS-before-visual-refresh-20261031-151933.zip`. The archive contains the pre-change application source, static assets and build output. To restore, stop the application and extract the archive to a separate location first; its top-level folder is `CMS`. Review and copy the desired files rather than blindly overwriting later work.

The refreshed homepage uses an original dark editorial hero, larger typography, geometric brand accents and sharper image-led solution cards. Design references were [The Webpage Builder](https://www.thewebpagebuilder.in/), [Endava](https://www.endava.com/) and [Thoughtworks](https://www.thoughtworks.com/). Globant was requested but blocked access during inspection. Reference code, media, customer claims and trademarks were not copied.

The industry band loops horizontally using a transform-only CSS animation and the local `wwwroot/js/industry-marquee.js` controller. There is no separate pause button: tap/click the strip or focus it and press Enter/Space to toggle a persistent pause. Its tooltip and accessible name explain the action; hovering or focusing the band pauses it temporarily. An IntersectionObserver and the document visibility event pause offscreen and hidden-page work. Reduced motion, unavailable browser support or disabled JavaScript display all four industries as a static, wrapping list. The visual duplicate is hidden from assistive technology. The continuous effect intentionally differs from the skill's preference for avoiding decorative loops, so it is confined to this single requested strip and can always be stopped.

The header and footer circle uses `wwwroot/Asset/Images/sg-logo-circle.png`, a 384px transparent crop of the supplied `../images/sticker_transparent.png`. Isolated background speckles were removed for clean small-size rendering; the supplied original is unchanged.
